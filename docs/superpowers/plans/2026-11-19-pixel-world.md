# 云上像素冒险：全局视觉改版

**Goal:** 将用户确认的鲜艳像素兔子与云上草地视觉应用到启动、首页、地图、制作、熨烫、收藏、自制图纸、设置和异常弹窗。
**Architecture:** 沿用 Cocos Creator 单场景、已有存储与游戏规则；新增共用 pixelBox、像素纹理和首页布局函数。AI 生成场景与透明标题为本地资源。网页启动页使用同样素材。首页主按钮进入关卡地图；已有进行中作品直接继续。
**Tech Stack:** Cocos Creator 3.8.8、TypeScript、Graphics、Sprite、Vitest。
**Spec:** 用户在本聊天确认的鲜艳蓝天、巨型像素云、绿色浮岛、围巾小兔与深紫山岩图；要求所有页面与物件统一风格。
